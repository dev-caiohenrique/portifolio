# Portfólio

Este é o projeto do portfólio. A arquitetura foi organizada da seguinte forma:

## Estrutura
- `src/`: Código-fonte (CSS, JS, Imagens, etc)
- `.tmp/`: Arquivos intermediários (não commitados)
- `scripts/`: Scripts isolados
- `docs/`: Manuais e procedimentos operacionais
- `tests/`: Testes
